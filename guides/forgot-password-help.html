Password Help Guide

Forgot a Password?

A calm way to approach password resets, account recovery, verification codes, and safer sign-in habits.

Estimated time: 5–10 minutesDifficulty: BeginnerPlain-English guide

Before you start

Stop if reset codes are not arriving or the account recovery options are unfamiliar. Repeated attempts can lock the account.

1

Use the official website or app

Go directly to the company’s website or app. Avoid clicking password reset links from unexpected emails.

2

Choose “Forgot password”

Use the official reset option and follow the prompts. You may need email, phone, or security questions.

3

Check verification methods

Make sure you can access the email or phone number where codes are sent.

4

Create a strong new password

Use a password you do not use anywhere else. A password manager can help organize this safely.

5

Update saved passwords

After resetting, update the saved password on your phone, browser, tablet, or password manager.

When to ask for help

If the issue still is not resolved, do not keep guessing. Write down what happened, what you tried, and any error messages you saw. Friendly Tech Concierge can help you sort through it calmly in your home.
